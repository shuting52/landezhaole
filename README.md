# 懒得找了 · 免费资源导航网站

> 找网站，懒得找了。

线上地址：https://landezhaole.pages.dev

「懒得找了」App 的网页版导航站：19 大分类、2320 个精选站点，打开即用，不用安装。

## 功能

- **2320 个站点**：云端 1767 条 + App 本地内置 553 条，合并去重（2026-10-25 快照，非实时同步）
- **站内搜索（按 App 逻辑）**：标题 / 简介 / 标签匹配，NEW 新站点置顶、其次 HOT；搜索时只显示结果列表，点“清空搜索”回到分类浏览
- **8 个搜索引擎**：站内、必应、百度、B站、百度网盘、阿里云盘、夸克网盘、谷歌；选非站内时回车或点搜索即跳对应引擎
- **顶部快捷程序坞**：前 10 个分类的彩色首字图标，鱼眼放大、粒子拖尾、悬停提示分类名，点图标跳到对应分类
- **卡片角标**：右上角统一七彩角标（HOT / NEW / 推荐 / 精选），压在卡片上边框
- **卡片图标**：对应站点的真实图标，多源兜底（Google → DuckDuckGo → 站点自带），点卡片整张直接跳转
- **上新提醒**：数据里有 NEW 标签的新站点时，右上角只弹一次汇总 Toast，点 Toast 直达新站点
- **更新弹窗**：版本变化时首次访问弹出更新日志（见下方“发新版”）
- **夜间模式、回到顶部**：夜间模式偏好保存在浏览器本地

## 目录

```

icon.png      网站图标（1600px）

```

## 本地预览

本仓库是纯静态站，不需要构建，直接用任意静态服务器打开根目录即可，例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 注意：直接用 `file://` 打开时，`data.json` / `version.json` 可能因浏览器安全策略读不到，请用上面的本地服务器方式。

## 部署到 Cloudflare Pages

1. 在 Cloudflare Pages 新建项目，连接本仓库。
2. 构建命令留空，输出目录填根目录（或直接把本仓库文件作为 Pages 项目的上传内容）。
3. 部署完成后访问分配的 `*.pages.dev` 域名；如需自定义域名，在 Pages 项目里绑定已接入 Cloudflare 的域名即可。

本站当前生产域名 `landezhaole.pages.dev` 即按此方式部署。

## 发新版（更新弹窗）

更新弹窗的数据源就是 `version.json`，逻辑如下：

1. 改 `version.json`：版本号 `version` +1（如 `1.0.0` → `1.1.0`），更新 `date`，在 `changelog` 里写清本次改动。
2. 如有站点变动，同步更新 `data.json`（新站点请打上 `NEW` 标签，才会触发上新 Toast）。
3. 重新部署到 Pages。

访客逻辑：

- 页面加载后读取 `version.json`，与浏览器本地记录的已看版本对比；
- 版本不同时，5 秒后弹出更新日志弹窗，点“知道了”或点遮罩关闭后记为已看，之后不再弹；
- 页脚有“查看更新日志”，随时可以手动再打开当前版本的弹窗。

## 数据更新说明

`data.json` 是快照，不是 App 云端数据的实时同步。App 侧站点库变化后，需要重新导出并合并去重（云端 + 本地内置），再替换 `data.json` 并重新部署，网站才会同步。
